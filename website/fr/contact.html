Nous contacter

MoonlightWeb est gratuit et open source, développé par une seule personne. Choisissez le canal adapté — Discord pour obtenir de l’aide et échanger avec la communauté, public sur GitHub pour tout ce qui concerne l’application, ou e-mail pour les sujets privés.

Discord — aide et communauté

Le moyen le plus rapide d’obtenir de l’aide. Le serveur est organisé pour qu’une question trouve sa réponse :

  • #qna — le forum d’aide : un fil par question, pour que tout reste consultable. Cherchez d’abord : votre problème est peut-être déjà résolu. Sinon, ouvrez un fil.
  • #announcements et #updates — les nouvelles versions et ce qui change, dès leur sortie.
  • #general — pour discuter avec les autres joueurs.
Rejoindre le Discord Forum d’aide, nouvelles versions et discussion.

GitHub — bugs et idées

Le meilleur endroit pour signaler un bug ou proposer une idée sur l’application. Les tickets sont publics : votre question et sa réponse profitent aussi au suivant — et aucun spam, puisqu’un compte GitHub est nécessaire.

Signaler un bug / proposer une fonctionnalité Ouvrez un ticket — le suivi des problèmes et des idées. Parcourir le projet Code source, versions et documentation.

E-mail — pour tout sujet privé

Pour ce qui n’a pas sa place dans un ticket public — presse, partenariats, signalements de sécurité ou question privée — l’e-mail fonctionne aussi. Réponse plus lente que sur Discord ou GitHub.

✉ Afficher l’adresse e-mail

Anti-robots : l’adresse est assemblée par votre navigateur au moment où vous interagissez avec le bouton ; elle n’apparaît donc jamais dans le code source de la page. Les robots collecteurs d’adresses — qui n’exécutent pas de scripts et se contentent de lire le HTML brut — ne la voient jamais, ce qui garde la boîte mail sans spam.

Laisser un pourboire

MoonlightWeb est gratuit, mais le serveur DNS partagé moonlightweb.top et le domaine coûtent de l’argent à maintenir en ligne. Si le projet vous est utile, un pourboire facultatif — le prix d’un café — aide beaucoup. ☕
