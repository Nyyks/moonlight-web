Sunshine · Apollo · Wolf · MultiSeat

Un client web pour votre hôte Sunshine

Vous streamez déjà avec Sunshine ? MoonlightWeb s’appaire avec lui comme le fait Moonlight — et vous permet d’y jouer dans un navigateur web, sur n’importe quel appareil, sans rien à installer côté client.

Comment cela fonctionne

Le serveur MoonlightWeb tourne sur une machine de votre réseau : le PC gamer lui-même, un autre PC, ou un serveur Linux ou un NAS avec Docker. Il embarque moonlight-common-c, la bibliothèque au cœur de Moonlight, dialogue avec votre hôte en protocole GameStream, et relaie vidéo, audio et entrées vers le navigateur via WebRTC.

Les hôtes avec lesquels il s’appaire

  • Sunshine et Apollo — découverts sur votre réseau via mDNS, ou ajoutés par IP ; appairés une seule fois avec le PIN que l’hôte affiche.
  • Wolf (Games on Whales) — appairé automatiquement : MoonlightWeb transmet le PIN à Wolf par son API.
  • MultiSeat — une machine Windows divisée en postes ; chaque poste est configuré et appairé séparément.

Installation en trois étapes

Installez MoonlightWeb

Sous Windows, macOS ou Linux avec les guides d’installation, ou dans Docker sur un serveur Linux ou un NAS.

Appairez votre hôte

Ouvrez MoonlightWeb dans un navigateur : votre hôte Sunshine apparaît à côté des autres. Saisissez le PIN qu’il affiche, une seule fois — l’appairage est mémorisé.

Jouez depuis n’importe quel navigateur

Téléphone, tablette, ordinateur portable, Chromebook ou TV : ouvrez la page et choisissez un jeu. Activez l’accès Internet pour jouer aussi loin de chez vous.

Vous partez de zéro ? Vous n’avez pas du tout besoin de Sunshine : installé sur le PC gamer, MoonlightWeb capture et encode cette machine elle-même, sans second serveur de streaming à configurer.

Sunshine, Apollo, Wolf et MultiSeat sont des projets indépendants ; Moonlight et moonlight-common-c appartiennent au projet Moonlight.
