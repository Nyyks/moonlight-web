Ouvrir votre hôte

Tapez le code de votre hôte pour l’ouvrir dans ce navigateur. Pensé pour les appareils sans barre d’adresse, où le lien de l’hôte ne peut pas être tapé.

Ce n’est pas un code d’hôte : il fait 26 lettres et chiffres, la fin du lien de l’hôte.

Le lien complet collé tel quel fonctionne aussi.

Où trouver le code ?

Sur le PC hôte, MoonlightWeb affiche son lien une fois l’accès Internet configuré, par exemple stream.moonlightweb.top/a1b2c3d4e5f6g7h8j9k0m1n2. Le code est la partie après le dernier / : 26 lettres et chiffres.

Une seule fois par appareil

Une fois un hôte déverrouillé avec son code PIN, ce navigateur s’en souvient. Si vous en déverrouillez deux ou plus, vous passez de l’un à l’autre par un menu dans l’application, sans rien retaper. Cette page retient aussi le dernier code ouvert d’ici.
