Open your host

Type your host's code to open it in this browser. Made for devices with no address bar, where the host's link cannot be typed.

That is not a host code: it is 26 letters and digits, the end of the host's link.

The whole link pasted in works too.

Where is the code?

On the host PC, MoonlightWeb shows its link once Internet access is set up, for example stream.moonlightweb.top/a1b2c3d4e5f6g7h8j9k0m1n2. The code is the part after the last /: 26 letters and digits.

Only once per device

Once a host is unlocked with its PIN, this browser remembers it. If you unlock two hosts or more, you switch between them from a menu in the app, with nothing to type again. This page also remembers the last code opened from here.
