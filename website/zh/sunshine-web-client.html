首页 / Sunshine 网页客户端
Sunshine · Apollo · Wolf · MultiSeat

为你的 Sunshine 主机打造的网页客户端

已经在用 Sunshine 串流？MoonlightWeb 像 Moonlight 一样与它配对——并在网页浏览器中游玩，适用于任何设备，客户端无需安装任何东西。

工作原理

MoonlightWeb 服务器运行在你网络中的一台机器上：游戏 PC 本身、另一台 PC，或者装有 Docker 的 Linux 服务器或 NAS。它内嵌 Moonlight 的核心库 moonlight-common-c，用 GameStream 协议与你的主机通信，并通过 WebRTC 把视频、音频和输入转发到浏览器。

它可配对的主机

  • Sunshine 和 Apollo — 通过 mDNS 在你的网络中被发现，或通过 IP 添加；用主机显示的 PIN 码配对一次即可。
  • Wolf（Games on Whales）— 自动配对：MoonlightWeb 通过 Wolf 的 API 把 PIN 码交给它。
  • MultiSeat — 将一台 Windows 机器划分为多个席位；每个席位单独设置和配对。

三步完成设置

安装 MoonlightWeb

按照安装指南装在 Windows、macOS 或 Linux 上，或在 Linux 服务器或 NAS 上用 Docker 运行。

配对你的主机

在浏览器中打开 MoonlightWeb：你的 Sunshine 主机会出现在其他主机旁边。输入它显示的 PIN 码，仅需一次——配对会被记住。

在任意浏览器中游玩

手机、平板、笔记本、Chromebook 或电视：打开页面，选择一款游戏。开启互联网访问，在外也能玩。

从零开始？你根本不需要 Sunshine：装在游戏 PC 上后，MoonlightWeb 会自己捕获并编码这台机器，无需再设置第二个串流服务器。

Sunshine、Apollo、Wolf 和 MultiSeat 是独立项目；Moonlight 和 moonlight-common-c 属于 Moonlight 项目。
