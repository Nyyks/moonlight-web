连接主机

打开你的主机

输入主机代码，即可在此浏览器中打开它。专为没有地址栏、无法输入主机链接的设备设计。

这不是主机代码：主机代码由 26 个字母和数字组成，即主机链接的末尾部分。

直接粘贴完整链接也可以。

代码在哪里？

在主机电脑上，设置好互联网访问后，MoonlightWeb 会显示其链接，例如 stream.moonlightweb.top/a1b2c3d4e5f6g7h8j9k0m1n2。代码就是最后一个 / 之后的部分：26 个字母和数字。

每台设备只需一次

主机用 PIN 码解锁后，此浏览器会记住它。如果你解锁了两台或更多主机，可在应用内的菜单中切换，无需重新输入。本页也会记住最近从这里打开的代码。
