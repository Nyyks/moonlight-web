联系

联系我们

MoonlightWeb 免费且开源，由一位开发者独立打造。选择合适的渠道——在 Discord 上获取帮助、与社区交流，与应用相关的一切请在 GitHub 上公开提出，私密事宜请发邮件。

Discord——帮助与社区

获取帮助最快的方式。服务器的组织方式让每个问题都能找到答案：

  • #qna——帮助论坛：每个问题一个帖子，便于搜索。请先查找：你的问题可能已经解决。否则，新开一个帖子。
  • #announcements 与 #updates——新版本及其变化，第一时间发布。
  • #general——与其他玩家聊天。
加入 Discord 帮助论坛、版本动态与聊天。

GitHub——问题与想法

报告应用 Bug 或提出想法的最佳去处。Issue 是公开的：你的提问及其回答同样能帮到后来者——而且没有垃圾信息，因为需要 GitHub 账户。

报告 Bug / 请求功能 提交 issue——问题与想法的跟踪处。 浏览项目 源代码、发行版与文档。

邮件——处理任何私密事宜

对于不适合放进公开 issue 的事情——媒体、合作、安全报告或私密问题——邮件同样可行。回复会比 Discord 或 GitHub 慢一些。

✉ 显示邮箱地址

防机器人：地址在你与按钮交互时由浏览器即时拼装，因此从不出现在页面源代码中。采集地址的机器人——它们不运行脚本，只抓取原始 HTML——永远看不到它，从而让邮箱免受垃圾邮件侵扰。
