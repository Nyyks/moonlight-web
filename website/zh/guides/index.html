安装指南

安装 MoonlightWeb — 选择你的平台

MoonlightWeb 是一个免费、开源（GPL-3.0）的服务器，把你的游戏主机串流到任何带浏览器的设备——手机、平板、笔记本、电视。在游戏 PC 上下载一次。其他任何设备都无需安装——只要一个网址。

选择你的操作系统

在 Windows 上安装向导式安装程序——一个向导，别的都不用配。 在 macOS 上安装Apple Silicon 指南，附 .pkg 安装程序。 在 Linux 上安装.deb、.rpm 或便携 AppImage。

你需要什么

  • 一台配备支持硬件编码 GPU 的游戏 PC——也就是运行你游戏的那台机器（Windows、macOS Apple Silicon 或 Linux）。
  • 不需要别的。MoonlightWeb 自己捕获并编码这台 PC——无需再装第二个串流服务器。已经在别处跑着 Sunshine、Wolf 或 MultiSeat？那些机器可以在同一个页面里配对。
  • 任何带现代浏览器的设备都可作客户端：Chrome、Edge、Safari 或 Firefox。无需应用、无需下载、无需账户。
不确定选哪个？装在运行你游戏的那台 PC 上——只有这台机器需要 MoonlightWeb 服务器。其他所有设备只需打开浏览器。
