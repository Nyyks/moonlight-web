安装指南 · Windows

把你的 Windows 游戏 PC 串流到任何浏览器

MoonlightWeb 是一个免费、开源（GPL-3.0）的服务器，把你的游戏主机串流到任何带浏览器的设备——手机、平板、笔记本、电视。在游戏 PC 上下载一次。其他任何设备都无需安装——只要一个网址。

你需要什么

  • 一台 Windows 10（2004+）或 11 的游戏 PC，配备支持硬件编码的 GPU——也就是运行你游戏的那台机器。要让它自己当主机需要 x64；arm64 版本也有，可作为你所配对主机的服务器使用。
  • 不需要别的。MoonlightWeb 自己捕获并编码这台 PC——无需再装第二个串流服务器。已经在别处跑着 Sunshine、Wolf 或 MultiSeat？那些机器可以在同一个页面里配对。
  • 任何带现代浏览器的设备都可作客户端：Chrome、Edge、Safari 或 Firefox。无需应用、无需下载、无需账户。

逐步安装

下载安装程序

从发布页面获取 Windows 安装程序——大多数 PC 用 x64 .exe，Windows-on-ARM 机器用 arm64 .exe。

运行向导式安装程序——在游戏 PC 上

向导会带你走完全部流程：静默安装手柄和方向盘驱动，询问是否允许互联网连接（远程串流会话，默认关闭），并提供 MoonlightWeb Virtual Display——一块供这台电脑串流的专属屏幕。别的都不用——无需配置第二个串流服务器。

完成后，托盘中会出现一个图标——服务器已在运行。安装到此为止。

在任何设备上打开浏览器

在 PC 本机上：https://localhost。从你网络上的其他设备：你的局域网 IP。要从网络之外游玩：启用互联网访问，应用便会给你一个直达这台机器的远程接入链接。你也可以使用自己的域名和证书。

你的 PC 已经在那里

这台机器一开始就列在那里，每块屏幕一张卡片——无需配对，也没有 PIN 码。你网络上的其他主机（Sunshine、Wolf、MultiSeat）会通过 mDNS 出现在旁边：那些只需配对一次——对于 Sunshine，在其网页中输入 MoonlightWeb 显示的 PIN 码——之后永久记住。

按下开始

选择一块屏幕、一款游戏或完整桌面。全屏、手柄在手——最高 4K HDR、240 fps，Wi-Fi 下延迟低于 20 毫秒。

疑难解答

主机没有出现在浏览器里

请确保客户端设备与游戏 PC 处于同一网络，并且 Windows 防火墙仍允许 MoonlightWeb（安装程序会自行添加规则）。你也可以通过 IP 手动添加主机。

HEVC 或 AV1 被置灰

你的浏览器无法硬件解码的编解码器选项会被自动禁用——这是正常的。H264 到处都能用；HEVC 和 AV1 是否可用取决于客户端设备的浏览器和 GPU。

弱网络下串流卡顿

降低串流分辨率并启用 Video Enhancement（视频增强）：串流会在客户端 GPU 上放大并锐化（WebGL2 或 WebGPU 运行 MoonlightWeb 自研放大算法），于是 720p 串流看起来接近 1440p。

网络受限？MoonlightWeb 会自动回退（UDP → TCP），因此在严格防火墙和恶劣的酒店 Wi-Fi 下也能继续工作。
