安装指南 · macOS

把你的 Mac 串流到任何浏览器

MoonlightWeb 是一个免费、开源（GPL-3.0）的服务器，把你的 Mac 串流到任何带浏览器的设备。在运行游戏的那台 Mac 上下载一次。其他每台设备只要打开一个网址。

你需要什么

  • 一台 Apple Silicon Mac（M1 或更新）——运行你游戏的那台机器。
  • 不需要别的。MoonlightWeb 自己捕获并编码这台 Mac（ScreenCaptureKit → VideoToolbox）——无需再装第二个串流服务器。已经在别处跑着 Sunshine、Wolf 或 MultiSeat？那些机器可以在同一个页面里配对。
  • 任何带现代浏览器的设备都可作客户端：Safari、Chrome、Edge 或 Firefox。无需应用、无需账户。

逐步安装

下载安装程序

从发布页面获取 arm64 .pkg。

运行向导式安装程序——在运行游戏的那台 Mac 上

安装向导会带你完成配置，包括可选的互联网连接（远程串流会话，默认关闭）。完成后，服务器即在运行。

随后 macOS 会请你为 MoonlightWeb 允许屏幕录制——没有它，这台 Mac 无法串流自己的屏幕。这是只有你才能授予的两项权限中的第一项；向导会为你打开对应的设置面板。

在任何设备上打开浏览器

在 Mac 本机上：https://localhost。从你网络上的其他设备：你的局域网 IP。要从网络之外游玩：启用互联网访问，应用便会给你一个直达这台机器的远程接入链接。你也可以使用自己的域名和证书。

你的 Mac 已经在那里

这台 Mac 一开始就列在那里，每块屏幕一张卡片——无需配对，也没有 PIN 码。你网络上的其他主机（Sunshine、Wolf、MultiSeat）会通过 mDNS 出现在旁边：那些只需用它们显示的 PIN 码配对一次，之后永久记住。

按下开始

选择一块屏幕、一款游戏或完整桌面。iPhone、iPad、另一台笔记本、一台电视——任何带浏览器的东西都能成为客户端。

⬇ 下载 macOS 版

macOS 会请你允许什么

苹果不允许任何安装程序代你授予这些权限——macOS 上的每个串流服务器都要求同样的权限。一共两项，MoonlightWeb 会在安装后的首次启动时一次性请求两项，那时你还坐在这台 Mac 前面：

  • 屏幕录制，在首次启动时。在系统设置 → 隐私与安全性 → 屏幕录制（macOS 15 及更新版本中名为屏幕与系统音频录制）中勾选 MoonlightWeb，然后退出并重新打开 MoonlightWeb——macOS 只对授权之后启动的程序应用该权限。在此之前，主机页面会把这台 Mac 显示为不可用，并原样说明这一点。
  • 辅助功能，紧接着一并请求。正是它让你的点击和按键到达这台 Mac。请在系统设置 → 隐私与安全性 → 辅助功能中勾选 MoonlightWeb。没有它，画面会出现而一切都没有反应——而且 macOS 自己不会给出任何提示，所以配置页面会说明这一点，并可以帮你打开该面板。

过程中，安装程序还会要求你的管理员密码（应用安装到 /Applications），并在第一页要求对“此软件包将运行一个程序以确定该软件能否安装”点击允许——那个程序就是安装程序自己的互联网页面。除此之外没有别的：安装程序已经在 macOS 防火墙中放行了 MoonlightWeb，因此不会出现传入连接的提示，也不会安装第二个串流服务器。

授予一次，此后保留。发布版本使用稳定证书签名，因此更新 MoonlightWeb 不会再次索要这些权限。

一条命令搞定——而且没有警告

MoonlightWeb 免费且开源，这也意味着它没有用付费的 Apple Developer ID 签名。因此 macOS 会对下载来的 .pkg 提示“无法打开，因为它来自身份不明的开发者”。这项检查只针对浏览器下载的文件，所以下面任意一条命令都能安装完全相同的软件包，无需任何额外点击：

brew install --cask linckosz/tap/moonlightweb
curl -fsSL https://moonlightweb.top/install.sh | bash

两者都会要求输入管理员密码，安装到 /Applications 并打开设置向导——同一个安装程序，同样的结果，少一个步骤。

疑难解答

macOS 拒绝打开安装程序：“身份不明的开发者”

这是预期行为，也无害：要消除该提示需要付费的 Apple Developer ID。使用上面两条命令之一就不会出现。如果你想用已经下载好的文件：在 macOS 15 Sequoia 及更新版本上先双击一次、让它被拒绝，然后打开系统设置 → 隐私与安全性，滚动到底部并点击仍要打开——旧的 Control-点按 → 打开的快捷方式已失效。终端等效命令：xattr -dr com.apple.quarantine ~/Downloads/moonlightweb-*.pkg。

画面有了，但鼠标和键盘没有反应

这是辅助功能权限：缺少它时，macOS 会完全静默地丢弃注入的点击和按键。请在系统设置 → 隐私与安全性 → 辅助功能中勾选 MoonlightWeb，然后退出并重新打开应用。

开关已经勾上了，还是不行

macOS 把权限绑定在应用的签名上，而不是它的名字上——于是旧副本或以不同方式构建的副本留下的条目仍然勾着，而正在运行的应用却被拒绝。在终端里清除它，让应用重新询问：

tccutil reset ScreenCapture com.moonlightweb.server
tccutil reset Accessibility com.moonlightweb.server

重新打开 MoonlightWeb，并在它重新出现在这两个面板中时勾选它。对于预发布版本，标识符是 com.moonlightweb.server.dev。

主机没有出现在浏览器里

请确保客户端设备与这台 Mac 处于同一网络。安装程序已在 macOS 防火墙中放行 MoonlightWeb，但第三方防火墙、或者会隔离客户端的访客 Wi-Fi 不会。你也可以通过 IP 手动添加主机。

在 iPhone 或 iPad 上游玩

在 Safari 里打开同一个网址——无需从 App Store 下载。你将获得多点触控触控板、带修饰键的原生虚拟键盘，以及带振动的完整游戏手柄支持。

弱网络下串流卡顿

降低串流分辨率并启用 Video Enhancement（视频增强）：串流会在客户端 GPU 上放大并锐化（WebGPU 运行 SGSRv1 + FSR1），于是 720p 串流看起来接近 1440p。

网络受限？MoonlightWeb 会自动回退（UDP → TCP），因此在严格防火墙和恶劣的酒店 Wi-Fi 下也能继续工作。
