Deinen Host öffnen

Gib den Code deines Hosts ein, um ihn in diesem Browser zu öffnen. Gedacht für Geräte ohne Adressleiste, auf denen sich der Link des Hosts nicht eintippen lässt.

Das ist kein Host-Code: Er besteht aus 26 Buchstaben und Ziffern, dem Ende des Host-Links.

Du kannst auch einfach den ganzen Link einfügen.

Wo finde ich den Code?

Auf dem Host-PC zeigt MoonlightWeb seinen Link an, sobald der Internetzugriff eingerichtet ist, zum Beispiel stream.moonlightweb.top/a1b2c3d4e5f6g7h8j9k0m1n2. Der Code ist der Teil nach dem letzten /: 26 Buchstaben und Ziffern.

Nur einmal pro Gerät

Sobald ein Host mit seiner PIN entsperrt ist, merkt sich dieser Browser ihn. Wenn du zwei oder mehr Hosts entsperrst, wechselst du über ein Menü in der App zwischen ihnen, ohne etwas erneut einzugeben. Diese Seite merkt sich außerdem den zuletzt von hier geöffneten Code.
