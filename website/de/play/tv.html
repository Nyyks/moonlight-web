Spiel deine PC-Spiele auf dem Wohnzimmer-TV

Wenn dein Fernseher oder deine TV-Box einen modernen Webbrowser hat, kann er zum MoonlightWeb-Client werden: Dein Gaming-PC streamt auf den großen Bildschirm. Keine App zu installieren — nur eine URL.

Was am besten funktioniert

  • Ein aktueller Browser mit Hardware-Videodekodierung. Das Erlebnis hängt vom Browser des Fernsehers oder der TV-Box ab: Je aktueller er ist, desto besser der Stream.
  • Ein Gamepad. Per USB angeschlossen oder per Bluetooth gekoppelt, macht es das Couch-Setup komplett. Oder einfach die Fernbedienung: Auf einer Android-TV-Box führen ihre Pfeiltasten und OK in der Direktnavigation von TV Bro durch die Seiten und ins Spiel, und langes Drücken auf OK öffnet das Menü des Streams.
  • Eine gute Verbindung zum Fernseher. Ethernet oder 5-GHz-WLAN hält das Bild scharf und die Verzögerung niedrig.

Keine Adressleiste? Gib stattdessen einen Code ein

In manchen TV-Browsern ist es mühsam, einen langen Link mit der Fernbedienung einzutippen. Sobald der Internetzugriff eingeschaltet ist, hat dein Host einen Code — das Ende seines Links. Such nach MoonlightWeb, öffne Verbinden, gib den Code ein, und der Browser öffnet deinen Host. Den zuletzt verwendeten merkt er sich fürs nächste Mal.

In drei Schritten eingerichtet

Installiere MoonlightWeb auf dem Gaming-PC

Windows, macOS (Apple Silicon) oder Linux — folge der Installationsanleitung für dein System. Dieser PC ist der einzige Rechner, auf dem etwas zu installieren ist.

Öffne es im Browser des Fernsehers

Gib die Adresse des PCs in deinem Netzwerk ein oder seinen Code auf der Seite „Verbinden“. Dein PC steht schon in der Liste: Gib die PIN ein, die er anzeigt, ein einziges Mal — ab jetzt ist der Fernseher dauerhaft vertrauenswürdig.

Schnapp dir den Controller

Wähl ein Spiel oder den ganzen Desktop, schalte in den Vollbildmodus und spiel vom Sofa aus.

Kein Smart-TV-Browser? Jeder Laptop oder Mini-PC, der per HDMI am Fernseher hängt, ist ebenfalls ein Client: Öffne darauf einen Browser und spiel genauso.
