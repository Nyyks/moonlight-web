Sunshine · Apollo · Wolf · MultiSeat

A web client for your Sunshine host

Already streaming with Sunshine? MoonlightWeb pairs with it the way Moonlight does — and plays it in a web browser, on any device, with nothing to install on the client.

How it works

The MoonlightWeb server runs on a machine of your network: the gaming PC itself, another PC, or a Linux server or NAS with Docker. It embeds moonlight-common-c, the library at the heart of Moonlight, speaks the GameStream protocol to your host, and relays video, audio and input to the browser over WebRTC.

The hosts it pairs with

  • Sunshine and Apollo — found on your network by mDNS, or added by IP; paired once with the PIN the host shows.
  • Wolf (Games on Whales) — paired automatically: MoonlightWeb hands Wolf the PIN through its API.
  • MultiSeat — one Windows machine split into seats; each seat is set up and paired on its own.

Set it up in three steps

Install MoonlightWeb

On Windows, macOS or Linux with the install guides, or in Docker on a Linux server or NAS.

Pair your host

Open MoonlightWeb in a browser: your Sunshine host shows up next to the others. Type the PIN it displays, once — the pairing is remembered.

Play from any browser

Phone, tablet, laptop, Chromebook or TV: open the page and pick a game. Turn on Internet access to play away from home too.

Starting from scratch? You don't need Sunshine at all: installed on the gaming PC, MoonlightWeb captures and encodes that machine itself, with no second streaming server to set up.

Sunshine, Apollo, Wolf and MultiSeat are independent projects; Moonlight and moonlight-common-c belong to the Moonlight project.
