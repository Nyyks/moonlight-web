Contact

Get in touch

MoonlightWeb is free and open source, built by one developer. Pick the channel that fits — Discord for help and to chat with the community, public on GitHub for anything about the app, or email for private matters.

Discord — help & community

The fastest way to get help. The server is organised so a question finds its answer:

  • #qna — the help forum: one thread per question, so it stays searchable. Look there first: your problem may already be solved. Otherwise, open a thread.
  • #announcements and #updates — new releases and what changed, as soon as they ship.
  • #general — to chat with other players.
Join the Discord Help forum, release news and chat.

GitHub — bugs & ideas

The best place to report a bug or suggest an idea about the app. Issues are public, so your question and its answer help the next person too — and there's no spam, since a GitHub account is required.

Report a bug / request a feature Open an issue — the tracker for problems and ideas. Browse the project Source code, releases and documentation.

Email — for anything private

For things that don't belong in a public issue — press, partnerships, security reports or a private question — email works too. Expect a slower reply than on Discord or GitHub.

✉ Show email address

Robot-proof: the address is assembled by your browser when you interact with the button, so it never appears in the page's source code. Address-harvesting bots — which don't run scripts and just scrape the raw HTML — never see it, which keeps the inbox spam-free.

Tip the project

MoonlightWeb is free, but the shared moonlightweb.top DNS server and domain cost real money to keep online. If the project is useful to you, an optional tip — the price of a coffee — helps a lot. ☕
